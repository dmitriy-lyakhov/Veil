# Сверка Android-клиента с дизайном

Источник: ветка `design` (`design/project/App.dc.html`, компактная раскладка телефона, `Android.dc.html`; токены — `design/project/ds/veil/tokens.json`).
Файлы `.dc.html` не открываются без среды холста (`support.js`), поэтому размеры взяты из их исходников: блок `renderVals()` и шаблон `App`
дают точные числа (px дизайна = dp приложения). Проверка на Pixel 3 (Android 12) — по снимкам экрана и логике кода.

## Совпадает с дизайном

| Элемент | Дизайн | Приложение |
|---|---|---|
| Палитра, тёмная и светлая | `tokens.json` | `Pal` в `Ui.kt` — значения совпадают |
| Шапка страниц | высота 56, заголовок 17/600 по центру, «назад» 44 слева с отступом 8 | то же (`MainActivity.render`) |
| Шапка главной | логотип 28 + «Veil» 20/600, плашка высотой 36, радиус 14, точка 10 (подключено — зелёная заливка, иначе рамка 2) | то же |
| Кольцо | 196 (150 при малой высоте), рамка 4, подпись 600 с размером `clamp(11, 22, ⌊0,62·размер/(длина·0,64)⌋)` | `RingView` |
| Покой | рамка ink, «дыхание» 1→1,03 за 4 с | то же |
| Подключение | рамка dim, дуга 107° за 1,1 с, три волны за 1,8 с (масштаб до 1,65, прозрачность 0,6→0) | то же |
| Подключено | красный диск, щит 38, подпись и таймер 15/700 цветом on-accent, две волны за 4,2 с, «хлопок» 0,92→1,05→1 за 0,5 с | то же; таймер от подъёма туннеля (`Store.since`) |
| Отключение | заливка accent → прозрачная, рамка и текст → ink за 0,7 с | то же |
| Ошибка | пунктирная рамка accent-ink, встряска 0,5 с | то же |
| Главная, герой | по центру высоты, зазор 24 (14), блок статуса 16/600 + 13/500 + строка трафика, кнопка раздельного доступа ≥ 44 со шевроном вниз | то же |
| Нижняя панель | радиус 16, поля 12/20/20, ручка 44×5, имя сервера 28/600 (22) со шевроном 22, подпись «протокол | адрес» | то же; панель выдвижная, как в AmneziaVPN (см. ниже) |\| адрес» | то же |
| Тексты статусов | «Подключено / Отключено», подсказки при подключении, закрытии, ошибке; «Раздельный доступ выключен» | `strings.xml` (ru/en) |

| Переключатель | дорожка 48×28, бегунок 22 с отступом 3, галочка во включённом | `Toggle` |
| Радио | круг 22 с рамкой 2 (accent-ink у выбранной), точка 10 | `radio()` |
| Кнопка | высота ≥ 52, радиус 14 | `button()` |
| Поля страниц | 16 по бокам, 4 сверху | `Pages.kt` |
| Reduce motion | поддержан | настройка приложения и системное «убрать анимацию» |

## Не совпадает или не сверено

- Вторая вкладка: в дизайне «Доступ» (выдача доступа к VPN: клиенты, роли), в приложении «Трафик». Выдача доступа с телефона не реализована.
- В «Настройках» дизайн — плоский список (Серверы, Подключение, Приложение, Резервная копия, Тема, Язык, О Veil) с переходом по строке; в приложении
  строки сгруппированы по разделам (СЕРВЕРЫ, ПОДКЛЮЧЕНИЕ, …) и тема/язык выбираются в шторке.
- Не сверены по числам: шторки выбора сервера и протоколов, страницы «Раздельный доступ» (сайты, приложения), «Сетевой интерфейс», «Журналы», «О Veil»,
  «Новый сервер» (мастер установки), страницы клиентов и каскада.
- Панель сервера на главной — выдвижная, как в AmneziaVPN (`Drawer.kt`): тянется за пальцем вверх и вниз, под именем раскрывается список «Серверы» (радио, «Добавить сервер»), без затемнения, навигация остаётся на месте; любое движение вверх раскрывает её до конца, вниз — сворачивает, даже если палец уже отпущен (доводка с плавным замедлением от текущей позиции), стрелка поворачивается, нажатие на имя и «назад» переключают её. Остальные шторки:
- Шторки анимированы: выезд снизу 260 мс, закрытие 200 мс (кнопка «×», «назад», тап по затемнению, выбор пункта), закрытие смахиванием вниз —
  шторка следует за пальцем, затемнение гаснет, по сдвигу > 80 dp или быстрому жесту уезжает, иначе возвращается; «Уменьшить движение» отключает анимацию.
- Не реализованы: переходы между страницами (140 + 320 мс), раскрытие списков и анимация переключателя (200 мс, растягивание бегунка при нажатии).
- Шрифт данных Arimo не подключён: таймер и строка трафика рисуются системным sans-serif.
- Версия протокола в подписи сервера («AmneziaWG (версия 3.1) | адрес») не показывается: клиенту она неизвестна.
- Размеры измерены по коду и снимкам, автоматического измерения DOM дизайна нет (нужна среда холста).
