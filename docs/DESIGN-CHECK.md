# Сверка приложения с дизайном v4

Метод: у дизайна (`App.dc.html`, окно 1000x700, платформа Windows, тёмная тема, ru) снимаются размеры DOM
(`getBoundingClientRect`, computed style) для каждого экрана из `SCREENS`; у приложения те же величины берутся из
дерева объектов Fyne тестом `TestMeasureDump` (`internal/gui/measure_test.go`):

    VEIL_MEASURE=client-new,settings VEIL_MEASURE_OUT=<папка> go test -run TestMeasureDump ./internal/gui

Результат: текст (x, y, размер) и карточки (x, y, ширина, высота, радиус) в координатах окна (у дизайна вычтена
панель заголовка 32 px). Допуск 2 px. Контрольно сняты и реальные снимки экрана (`tools/uishot.sh`, теперь с `VEIL_MULTI=1`,
чтобы запуск не упирался в уже работающий Veil).

## Что не совпало и не исправлялось

* Нижняя граница страницы: в дизайне блок кнопок в окне 700 px упирается в низ (Отмена доходит до 670 px при высоте области 668),
  в приложении блок целиком в окне, ниже на ~2 px.
* Переключатель-тумблер 46x26 против 48x28 в дизайне (виджет `switchWidget`).
* Экраны, помеченные «нужно», в этой итерации по DOM не выравнивались: Главная (круг и плитки), Проверка входов,
  Сервер, Управление, мастера каскада, установка протоколов, Журналы, О Veil, Обновление, Трафик, Язык, Подключение,
  Раздельное. Для них действует только глобальная поправка шага/шапки.
* Блок «Роль» и кнопка «Поделиться каскадом…» на вкладке «Доступ → Подключение» добавлены в приложении сверх макета
  (v4 их не содержит), потому смещают нижние кнопки на ~25 px.
